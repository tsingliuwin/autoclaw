# 场景化海报手册

SKILL.md 的质量清单管"合格",本手册管"像行家"。顺序:先定场景 → 套构图与配色 → 按信息层级填内容 → 用易错点自检。

## 构图公式

九个排版公式其实是一族:**对齐轴(居中/左/右) × 图文关系(底图衬托 / 图文上下对称 / 图片穿插)**。

- **居中对齐**:正式、庄重 → 政务公告、地产、节日、发布会邀请
- **左对齐**:信息量大、阅读效率最高,中文海报的默认首选 → 促销、招聘、知识类
- **右对齐**:常配"图左文右"的变体 → 美食、产品特写
- 图文占比:5:5 均势或 3:7 主次;说明性小字(时间地点备注等)可以不守栅格
- 同一公式换图、换配色、换字体组合,气质完全不同——先套公式定骨架,再换皮调气质

## 场景速查

| 场景 | 构图 | 配色 | 第一视觉 |
| :--- | :--- | :--- | :--- |
| 促销/电商 | 左对齐或强分裂 | 红橙黄高饱和 | 折扣/价格数字 |
| 活动/会议 | 居中 | 主题色+深底 | 活动名 |
| 招聘 | 左对齐 | 品牌蓝/绿 | 岗位名+薪资 |
| 餐饮/美食 | 图左文右或大图打底 | 暖色(红橙黄) | 菜品实拍 |
| 节日/节气 | 居中 | 传统配色 | 节日符号+大字 |
| 知识/课程 | 左对齐 | 低饱和底+一个强调色 | 收益式标题 |
| 地产/政务公告 | 居中 | 蓝金/红金/深灰 | 机构名或主标 |
| 品牌/产品发布 | 大面积留白 | 深色高级感或纯白 | 产品本身 |

## 各场景信息层级与易错点

信息层级按"→"递减,排前面的必须视觉最大。

**促销/电商**
- 层级:活动主标 → 到手价/折扣 → 限时词(限时/秒杀/仅剩 N 件) → 商品图 → 二维码
- 价格锚定:原价划线做锚点,到手价放大加粗,对比越直白数字越有效
- 易错:折扣数字不够大(它是唯一主角);原价没划线;商品图堆太多张

**活动/会议/演出**
- 层级:活动名 → 时间 → 地点 → 票价/报名方式 → 主办方
- 时间地点是报名转化的命门,字号不能小于主标的一半
- 易错:时间地点埋进底部小字;缺报名入口(二维码/链接)

**招聘**
- 层级:公司(Logo 信任位) → 岗位名(最大) → 薪资范围+城市 → 福利亮点(胶囊标签 ≤3) → 投递二维码
- 蓝绿传达稳定信任;信息真实比浮夸更重要,虚假薪资毁品牌
- 易错:不写薪资范围;二维码太小扫不出;岗位堆超过 3 个

**餐饮/美食**
- 层级:菜品实拍 → 品名 → 卖点(鲜/辣/手作) → 价格/优惠 → 门店与营业时间
- 暖色刺激食欲;图片必须高饱和明亮,发灰的图直接毁掉整张海报
- 易错:菜品太多塞满画面(一图 1-3 道招牌即可);用冷色调

**节日/节气**
- 层级:节日名+符号 → 情绪文案 → 放假安排/活动信息 → 品牌角标
- 传统配色有惯性:春节红金、中秋蓝金月白、圣诞红绿、端午粽绿;放错色系会很怪
- 易错:放假日期不标调休;装饰元素抢过文字;用了与节日无关的符号

**知识/课程/讲座**
- 层级:收益式标题("7 天学会 XX",不是课程名) → 讲师/机构背书 → 数字背书(课时/学员数/年限) → 时间与报名码
- 低饱和底色+一个强调色,显得克制可信
- 易错:标题写课程名不写用户收益;背书数字造假

**地产/政务/正式公告**
- 层级:机构名/主标 → 事项 → 时间地点 → 落款+日期
- 居中构图、稳重字体、大量留白;蓝金/红金显庄重
- 易错:花哨字体和撞色;缺落款或日期

**品牌/产品发布**
- 层级:产品图/产品名 → 一句话卖点 → 发布时间 → 品牌角标
- 深色底或纯白+大留白,文案越少越高级;产品即主角
- 易错:卖点罗列超过一条;文字抢过产品

## 社媒封面规范

- **小红书**:只支持 1:1、3:4、4:3 三种比例,**3:4(1080×1440)占屏最大、观感最好**,做封面默认选它;标题大字+亮色关键字;同一账号封面风格统一(影响人设与推荐流量);多图笔记所有配图先统一尺寸,否则系统自动补白边
- **公众号首图(900×383)**:在手机信息流里是缩略图,标题 3-8 字、元素 ≤2 个,缩小到拇指大小仍要可读
- **OG 分享卡(1200×630)**:文字占比 ≤20%,品牌角标固定一角,链接预览里它只有指甲盖大
- **视频封面(1280×720)**:主标题放左侧 1/3(右侧常被时长标签遮挡)

## 文字压图三招

文字必须叠在图片上时(识别性原则):① 放到背景干净简单的地方;② 背景压暗、模糊或统一色调;③ 文字底部加不透明色块,或给文字加描边/投影。黑底配白字/黄字对比最强。
